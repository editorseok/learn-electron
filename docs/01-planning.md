# 01. 기획 따라하기

코드를 쓰기 전에 앱이 어떤 문제를 해결할지 먼저 정합니다. 이 단계에서는 아직 React나 Electron 코드를 작성하지 않습니다.

## 1단계: 사용자 정하기

이 앱의 사용자는 학습 내용을 정리하고 복습하고 싶은 사람입니다. 예를 들면 TypeScript, React, Electron을 공부하면서 짧은 노트를 쌓아 가는 초보 개발자입니다.

직접 작성해 볼 문장:

```txt
나는 학습자가 공부한 내용을 노트로 기록하고, 나중에 JSON 파일로 저장해서 다시 열 수 있는 데스크톱 앱을 만든다.
```

## 2단계: 핵심 기능 고르기

처음 버전에는 너무 많은 기능을 넣지 않습니다. 아래 기능만 목표로 합니다.

- 노트 생성
- 노트 수정
- 노트 삭제
- 태그 검색과 필터
- 완료 여부 체크
- 복습 날짜 입력
- JSON 저장
- JSON 불러오기

Markdown 미리보기, 자동 저장, 다크 모드는 나중에 확장할 기능으로 남깁니다.

## 3단계: 화면 나누기

화면은 세 영역으로 나눕니다.

```txt
상단
  새 프로젝트, 불러오기, 저장, 다른 이름으로 저장

왼쪽
  검색창, 태그 필터, 노트 목록

가운데
  선택한 노트 편집

오른쪽
  프로젝트 이름, 진행률, 파일 상태, 복습 날짜
```

초보자에게 중요한 점은 화면을 먼저 나누고 나서 컴포넌트를 생각하는 것입니다. UI를 한 덩어리로 만들면 나중에 수정하기 어렵습니다.

## 4단계: JSON 데이터 구조 정하기

앱 데이터는 하나의 JSON 파일로 저장합니다.

```json
{
  "schemaVersion": 1,
  "title": "LearnApp 학습 노트",
  "notes": [],
  "settings": {
    "theme": "system",
    "lastOpenedNoteId": null
  },
  "updatedAt": "2026-05-23T00:00:00.000Z"
}
```

노트 하나는 아래 형태입니다.

```json
{
  "id": "note-example",
  "title": "Electron 구조 이해하기",
  "content": "main, preload, renderer 역할을 나눈다.",
  "tags": ["electron", "architecture"],
  "completed": false,
  "reviewDate": null,
  "createdAt": "2026-05-23T00:00:00.000Z",
  "updatedAt": "2026-05-23T00:00:00.000Z"
}
```

`schemaVersion`은 나중에 파일 구조가 바뀌었을 때 이전 JSON 파일을 변환하기 위해 둡니다.

## 5단계: 완료 기준 정하기

아래 항목을 모두 만족하면 첫 버전이 완성된 것입니다.

- 앱이 `npm run dev`로 실행된다.
- 새 노트를 만들 수 있다.
- 노트 제목, 내용, 태그, 복습 날짜를 수정할 수 있다.
- 완료 상태를 바꿀 수 있다.
- JSON 파일로 저장할 수 있다.
- 저장한 JSON 파일을 다시 불러올 수 있다.
- `npm run test`가 통과한다.
- `npm run build`가 통과한다.
